# CarVia 🔐 SSO Service

Сервіс автентифікації та авторизації користувачів.

## 🛠 Технології

- Go
- JWT
- PostgreSQL

## ⚙️ Функціонал

- Реєстрація користувачів
- Авторизація користувачів
- Генерація JWT токенів
- Отримання профілю користувача
- Оновлення профілю
- Завантаження аватару

## 📡 Ендпоінти

- `/api/sso/register` - реєстрація нового користувача
- `/api/sso/login` - авторизація користувача
- `/api/sso/user_profile` - отримання профілю користувача
- `/api/sso/update_user_profile` - оновлення профілю користувача

## 🔑 JWT

- Використовується для доступу до захищених ендпоінтів
- Передається через заголовок:
  `Authorization: Bearer <token>`

## 🚀 Запуск

```bash
go run main.go
```
